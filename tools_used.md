| Tool | Purpose |
|---|---|
| **Python** | Main programming language for application logic |
| **Flask** | Web framework used to create pages, routes, login, bookings, and admin features |
| **Visual Studio Code** | Code editor used to write and manage the project |
| **Python virtual environment (`.venv`)** | Keeps project dependencies separate from other Python projects |
| **pip / `python -m pip`** | Installs Python packages |
| **MySQL Server** | Stores users, destinations, tour packages, and bookings |
| **MySQL Workbench** | Creates the database, runs SQL commands, and views table data |
| **`mysql-connector-python`** | Connects the Flask application to MySQL |
| **SQL** | Creates tables and retrieves or updates database records |
| **HTML/Jinja templates** | Builds web pages such as login, packages, destinations, bookings, and admin pages |
| **CSS** | Styles the website layout and appearance |
| **Flask-WTF / CSRFProtect** | Protects forms from CSRF attacks |
| **Werkzeug security** | Hashes passwords and verifies login passwords securely |
| **python-dotenv** | Loads configuration values from the `.env` file |
| **`.env` file** | Stores private settings such as database credentials and Flask secret key |
| **Git** | Tracks project changes and supports version control |
| **PowerShell/VS Code Terminal** | Runs the application and project commands |
| **Web browser / VS Code integrated browser** | Tests the working website locally |
| **Bootstrap concepts/CSS styling** | Used as a beginner-friendly approach for improving page appearance, where applicable |
